# Agentic AI

## Summary of the DeepLearning.AI Agentic AI Course

The DeepLearning.AI Agentic AI course focuses on building AI systems that can reason, plan, use tools, and carry out multi-step tasks with increasing autonomy. The central idea is that modern AI agents are not just chatbots; they are workflows that combine language models with structured decision-making, external tools, memory, and execution loops.

### Core concepts

- Agentic workflows: moving beyond single-turn prompts toward systems that can break a task into steps, evaluate progress, and adapt when constraints change.
- Tool use: giving models access to functions such as search, code execution, databases, APIs, and retrieval systems so they can act on real-world information.
- Planning and reasoning: prompting and orchestration patterns that help models reason through goals, choose actions, and revise plans when needed.
- Memory and context: maintaining short-term state, long-term knowledge, and task-specific context so the agent behaves consistently across iterations.
- Guardrails and evaluation: validating outputs, checking for reliability, and reducing failure modes through structured prompts, tests, and human-in-the-loop review.
- Multi-agent patterns: coordinating specialized agents for sub-tasks such as planning, retrieval, coding, or verification.


### Key takeaway

The course teaches that strong agentic systems are built from a combination of model capability, workflow architecture, tool integration, and disciplined evaluation. The real power comes from connecting reasoning to action in a controlled, observable way.
