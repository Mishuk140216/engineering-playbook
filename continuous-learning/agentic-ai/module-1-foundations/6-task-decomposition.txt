এই lesson-এর মূল বিষয় হলো Task Decomposition।
এর অর্থ হলো বড় একটি কাজকে ছোট ছোট step-এ ভাগ করেAgentic Workflow তৈরি করা।
উদাহরণ: AI দিয়ে একটি research essay লিখাতে চাইলেশুধু LLM-কে “Write an essay” বলার পরিবর্তে:

Topic
1. Create outline
2. Search web
3. Write first draft
4. Review
5. Revise
Final essay

যদি result ভালো না হয়, workflow আরও ভেঙে বা পরিবর্তন করতে হবে।
অর্থাৎ: build → evaluate → improve

প্রতিটি step-এর জন্য ভাবতে হবে:
Can LLM do it?
Can an API/function do it?
Can another tool do it?

যেমন customer order:
Email
Extract order number
Query database
Generate reply
Send email

Agentic workflow-এর building blocks হতে পারে:

LLM
API
Function
Database
RAG
Specialized AI model
Code execution

সবচেয়ে গুরুত্বপূর্ণ কথা:

Complex task
→ ছোট steps
→ প্রতিটি step-এর জন্য suitable tool
→ evaluate
→ improve

Interview-এর জন্য:

Task decomposition means breaking a complex task into smaller steps
that can be handled by LLMs, APIs, functions, or other tools.
