এই lesson-এর মূল বিষয় হলো Tool Use — অর্থাৎ LLM-কে কিছু function/tool ব্যবহার করার সুযোগ দেওয়া, 
যাতে LLM শুধু নিজের knowledge থেকে answer না দিয়ে প্রয়োজন হলে বাইরে থেকে information নিতে বা 
কোনো action করতে পারে।

সহজভাবে, মানুষ যেমন calculator, phone, computer ইত্যাদি tool ব্যবহার করে বেশি কাজ করতে পারে, 
তেমনি LLM-ও function ব্যবহার করলে আরও বেশি কাজ করতে পারে।

Tool Use কী?

Tool হলো মূলত এমন একটি function, যেটা আমরা LLM-এর জন্য তৈরি করে দিই। 
LLM প্রয়োজন মনে করলে সেই function call করার request করতে পারে।

উদাহরণ:

ধরো তুমি LLM-কে জিজ্ঞেস করলে:

“What time is it now?”

শুধু LLM-এর কাছে এই information নাও থাকতে পারে, কারণ তার training data পুরোনো হতে পারে।

কিন্তু আমরা তাকে একটি function দিলাম:

getCurrentTime()

তখন workflow হবে:

Question → LLM → Decide to use tool → getCurrentTime() → Current Time → LLM → Final Answer

যেমন tool থেকে 3:20 PM পাওয়া গেল, তখন LLM বলতে পারে:

“It is 3:20 PM.”

এখানে গুরুত্বপূর্ণ বিষয় হলো LLM নিজে function-এর কাজ করছে না। LLM শুধু decide/request করছে 
যে function call করা দরকার। Function actual কাজ করে result ফেরত দেয়।

আর সবসময় tool ব্যবহার করতে হবে এমনও নয়।

যদি user জিজ্ঞেস করে:

“How much caffeine is usually in green tea?”

এখানে getCurrentTime() দরকার নেই।

তাই:

Question → LLM → Direct Answer

অর্থাৎ LLM available tools দেখে প্রয়োজন হলে tool ব্যবহার করে, প্রয়োজন না হলে সরাসরি answer দেয়।

এটা আগের hard-coded workflow থেকে আলাদা।

আগের ক্ষেত্রে developer বলতে পারে:

Always → Web Search → Then Answer

এখানে developer আগে থেকেই ঠিক করে দিয়েছে কখন web search হবে।

Tool use-এর ক্ষেত্রে:

LLM → Look at Available Tools → Decide Which Tool to Use

অর্থাৎ decision-টা LLM-এর হাতে থাকে।

Tool-এর আরও কিছু example:

1. Web Search

User: “Find Italian restaurants near Mountain View.”

Question → LLM → Web Search Tool → Search Results → LLM → Answer

2. Database Tool

User: “Show me customers who bought white sunglasses.”

Question → LLM → Database Tool → Customer Data → LLM → Answer

3. Calculator / Interest Tool

User: “If I deposit $500 for 10 years at 5%, how much will I have?”

Question → LLM → Calculation Tool → Result → LLM → Answer

অর্থাৎ developer-কে আগে চিন্তা করতে হবে application-এর কী কী কাজ করতে হবে, 
তারপর সেই কাজগুলোর জন্য appropriate tools তৈরি করতে হবে।

একটি application-এ একাধিক tool-ও থাকতে পারে।

যেমন একটি Calendar Assistant-এর কাছে থাকতে পারে:

checkCalendar()

makeAppointment()

deleteAppointment()

User বলল:

“Find a free slot on Thursday and make an appointment with Alice.”

LLM নিজে stepগুলো decide করতে পারে:

User Request → LLM → checkCalendar() → Free Time → LLM → makeAppointment() → 
Confirmation → LLM → Final Answer

ধরো Thursday-তে 3 PM free পাওয়া গেল।

তাহলে:

checkCalendar() → 3 PM Free

তারপর LLM সিদ্ধান্ত নিল:

3 PM → makeAppointment(Alice, 3 PM)

Appointment successfully তৈরি হলে সেই result আবার LLM-এর কাছে যাবে। তারপর LLM user-কে বলতে পারবে:

“Your appointment with Alice is set for 3 PM on Thursday.”

তাই পুরো concept-টা মনে রাখার সবচেয়ে সহজ way:

Tool Use = LLM-কে প্রয়োজন অনুযায়ী function call করার ক্ষমতা দেওয়া।

User Request → LLM → Choose Tool (if needed) → Tool → Result → LLM → Final Answer

আর যদি tool দরকার না হয়:

User Request → LLM → Final Answer

এই কারণেই Tool Use Agentic AI-এর জন্য গুরুত্বপূর্ণ। LLM শুধু কথা বলতে পারে না, tool ব্যবহার করে information gather করতে এবং actual action নিতে পারে।

নতুন Technical Terms:

Tool Use → LLM-এর প্রয়োজন অনুযায়ী external function/tool ব্যবহার করার ability।
Tool → LLM যে function call করার request করতে পারে।
Function → নির্দিষ্ট একটি কাজ করার জন্য লেখা code।
Function Call → কোনো function চালানোর request।
Tool Invocation → কোনো tool/function ব্যবহার করার জন্য call করা।
Tool Result → tool কাজ করার পর যে information/result ফেরত দেয়।
Hard-coded → developer আগে থেকেই code-এর মধ্যে নির্দিষ্ট করে দেওয়া workflow বা step।
Web Search Tool → internet থেকে information খোঁজার tool।
Database Tool → database থেকে information retrieve করার tool।
Calculator / Calculation Tool → mathematical calculation করার tool।
Calendar Assistant → calendar-related কাজ করার জন্য তৈরি AI agent।
Multi-tool Use → একটি LLM-এর কাছে একাধিক tool available থাকা এবং প্রয়োজন অনুযায়ী tool নির্বাচন করা।
Tool Selection → available tools-এর মধ্যে কোন tool ব্যবহার করবে তা নির্ধারণ করা।
External Information → LLM-এর নিজের knowledge-এর বাইরে tool থেকে পাওয়া নতুন information।
